Go 1.27 for Mac OS X 10.9 Mavericks. It installs beside Go 1.26: this toolchain lives in
`/usr/local/mavergreen/go127` and is `go-127` on every new login shell's path. Bare `go` stays with
whichever Go was installed first; `sudo mavergreen select go go127` moves it.

- **TLS trust is unchanged from Go 1.26 for Mavericks, and differs from upstream Go 1.27 on
  purpose.** On darwin, `SSL_CERT_FILE` and `SSL_CERT_DIR` add CA files to the keychain-union
  trust store; they do not replace the keychain, and a certificate you set to "Never Trust" in
  Keychain Access stays rejected. `GODEBUG=x509sslcertoverrideplatform` has no effect here.
- **A new shared CA location.** Programs also read
  `/usr/local/mavergreen/ca-certs/etc/openssl/certs/ca-certificates.crt` when it exists.
- **The cross toolchain needs macOS 13 or later**, as upstream Go 1.27 does. It still builds
  programs that run on 10.9.
- Go's verifier does not fetch missing intermediate certificates; a server that omits them fails
  verification, as with Go on Linux. `GODEBUG=x509usefallbackroots=0` uses Apple's verifier instead.
